# VIACO Image Assets

Place image files for the VIACO website in this folder (`public/viaco/`), then set the corresponding `src` path in [`src/config/assets.ts`](../../src/config/assets.ts) (for example, `src: "/viaco/hero-platform-preview.png"`).
